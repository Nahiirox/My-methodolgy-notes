# Web Proxies — Burp & ZAP Setup

Launch from terminal:

```bash
burpsuite
```

```bash
zaproxy
```

JAR fallback (any OS with JRE):

```bash
java -jar </path/to/burpsuite.jar>
```

Burp community → temporary project only, no save. Pro → persistent projects, active scanner, fast Intruder, extensions. ZAP → fully free, no throttle, growing feature parity.

> [!tip] No Burp Pro → use ZAP for active scanning and full fuzzing without rate limits hitting you mid-exam
